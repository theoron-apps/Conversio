# GTA V Enhanced

| | |
|---|---|
| Сюжетный режим | ✅ Работает |
| GTA Online | ❌ Не работает на Mac ни в Conversio, ни в CrossOver: античит BattlEye блокирует Wine |
| Графика | Только DirectX 12 → нужен **D3DMetal** |
| Рекомендуемый Mac | M1 Pro или новее, от 16 ГБ памяти, macOS 26 |

## Подготовка

1. Установите Conversio по [гайду](install.ru.md).
2. Импортируйте D3DMetal по [гайду](d3dmetal.ru.md) — без него игра не запустится.
3. Установите **Grand Theft Auto V Enhanced** в Steam внутри Conversio.

Когда игра появится в библиотеке, Conversio сам применит профиль: D3DMetal и DLSS через MetalFX. Это видно в **Настройках игры** (правый клик по обложке) — сверху блок «Профиль Conversio».

## Первый запуск

1. Нажмите **Играть**. Сначала запустится **Rockstar Games Launcher** — при первом запуске он сам доустанавливается, это может занять пару минут.
2. Войдите в аккаунт Rockstar в лаунчере.
3. В меню игры выберите **Story Mode**.

## Если игра не запускается

- **`ERR_GFX_D3D_NOD3D12`** — D3DMetal не импортирован, не выбран или взят из Game Porting Toolkit 3.0: игре нужна версия 4.0 или новее. Проверьте **Настройки → Движок** и графику в настройках игры.
- **Лаунчер Rockstar висит на загрузке** — закройте всё кнопкой **Остановить всё** на странице бутылки и запустите снова.
- **После обновления игры перестало работать** — такое бывает: обновления GTA иногда ломают совместимость. Напишите нам в [отчёт об игре](https://github.com/theoron-apps/Conversio/issues/new/choose).
